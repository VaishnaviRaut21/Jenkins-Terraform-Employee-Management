# Employee Management System

## Project Overview

This project demonstrates a web-based Employee Management System with an automated CI/CD pipeline using Jenkins and Infrastructure as Code using Terraform.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git
- GitHub
- Jenkins
- Terraform

## Application Features

- View employees
- Add employees
- Delete employees
- Store employee information in SQLite

## CI/CD Pipeline

The Jenkins pipeline contains:

1. Checkout
2. Install Dependencies
3. Build
4. Test
5. Package
6. Deploy

## Infrastructure as Code

Terraform is used to provision application deployment configuration and environment configuration.

## Testing

Automated tests are executed using pytest.
